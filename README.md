Entry for the [Make the AI judge feel curious](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311) bounty on make.fun.

`main.py` (Python 3.13, stdlib only, no network) writes one short text to `/output/entry.txt`: a calm, concrete mystery — a lighthouse keeper, a light turning a half-second late, and a second cup set out for someone the light seems to be waiting for. Nothing is explained; the reader is left wondering who it is waiting for.

Run it with `python3 main.py`. It creates `/output` if missing. `OUTPUT_PATH` overrides the output path for local testing only.
